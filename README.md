# Openstack
OpenStack is a set of software components that provide common services for cloud infrastructure.<br>
## Índice<br>
OpenStack es una plataforma de software libre y de código abierto para la creación y gestión de nubes privadas y públicas. Funciona como un sistema operativo para la nube que ofrece Infraestructura como Servicio (IaaS), permitiendo a las organizaciones controlar grandes grupos de recursos de cómputo, almacenamiento y redes a través de una interfaz web, línea de comandos o APIs.<br>

## Componentes principales<br>
- Nova (Compute): Gestiona las máquinas virtuales y los recursos de procesamiento (instancias).
- Neutron (Networking): Controla las redes virtuales, asignación de IPs, routers y firewalls.
- Cinder (Block Storage): Proporciona almacenamiento persistente de bloques para las instancias.
- Swift (Object Storage): Almacena y recupera datos de objetos no estructurados a través de una API.
- Glance (Image Service): Almacena y gestiona las imágenes de los sistemas operativos para crear instancias.
- Keystone (Identity): Ofrece un servicio centralizado de autenticación y autorización de usuarios.
- Horizon (Dashboard): Proporciona la interfaz gráfica web (panel de control) para administradores y usuarios.
- Heat (Orchestration): Permite definir y automatizar la infraestructura como código mediante plantillas.
- Ceilometer (Telemetry): Se encarga de la monitorización, recopilación de datos y métricas del uso de la nube.

## Entorno de pruebas<br>
Para realizar pruebas con OpenStack se necesita un entorno compatible, con recursos de computación, almacenamiento y red. La instalación debe adaptarse a los requisitos del proyecto y a los recursos disponibles.
