# Openstack
OpenStack is a set of software components that provide common services for cloud infrastructure.<br>
## Índice<br>
OpenStack es una plataforma de software libre y de código abierto para la creación y gestión de nubes privadas y públicas. Funciona como un sistema operativo para la nube que ofrece Infraestructura como Servicio (IaaS), permitiendo a las organizaciones controlar grandes grupos de recursos de cómputo, almacenamiento y redes a través de una interfaz web, línea de comandos o APIs.<br>
